# Рациональное зерно

Локальная сатирическая визуальная новелла об Александре — человеке, который пытается решить взаимность как инженерную задачу и систематически превращает чужое «нет» в повод для следующей итерации.

Сюжет написан заново: это не сборник цитат, а самостоятельная история, собранная из характерных моделей поведения, речи, интересов и самооправданий героя.

## Windows

Дважды щёлкните `ОТКРЫТЬ_НОВЕЛЛУ.bat`. При первом запуске скрипт установит недостающие локальные компоненты, соберёт проект и откроет новеллу в браузере.

## Android

Перенесите `Рациональное_зерно.apk` на телефон и установите как обычное приложение. Оно работает офлайн и не требует сервера или браузера.

Чтобы пересобрать APK после изменений, дважды щёлкните `СОБРАТЬ_APK.bat`. Новая версия появится рядом с BAT-файлом.

## Управление

- нажмите на панель продолжения или вариант ответа;
- `1`, `2`, `3`, `4` — выбрать реплику с клавиатуры;
- `Escape` — открыть меню;
- `M` — включить или выключить фон дождя;
- прогресс хранится только на устройстве.

## Сохранения и концовки

В меню доступны автосейв и шесть ручных слотов. Перед загрузкой, перезаписью, удалением слота и новой игрой есть подтверждение. Новая игра заменяет только автосейв: ручные слоты и коллекция концовок сохраняются. Старый сейв v3 переносится автоматически. В Android основная копия хранится в системном хранилище приложения, а прежняя WebView-копия оставлена для совместимости. Удаление приложения или очистка его данных удалит прогресс.

Открытые концовки можно перечитать без изменения текущей игры. Для закрытых показаны названия и подсказки, но не финальный текст.

## Обновления внутри Android-приложения

Один раз установите новый APK 1.1.0 поверх прежнего, не удаляя приложение. Старый APK 1.0 ещё не содержит загрузчик обновлений и не сможет получить его по воздуху.

При запуске и возвращении в приложение проверяется публичный адрес `https://rational-seed-novel.workspace-vo-3629.chatgpt.site/api/release`. При наличии новой версии показываются патчноут, размер и кнопка «Скачать и обновить». Загружается ZIP с HTML/CSS/JS и графикой, а не APK. Перед переключением ожидается запись сохранений. Архив проверяется по SHA-256, разрешены только HTTPS-ссылки этого сайта. При неудачном запуске Capgo Updater возвращает предыдущую рабочую сборку. Телеметрия Capgo выключена; прогресс и переписки серверу не передаются.

Обновления добровольные, без интернета работает установленный контент. При следующем холодном запуске отложенная новая версия снова предлагается. Полноценный откат защищает от сбоя запуска, а не от любой логической ошибки в сценарии.

### Как выпускать следующие версии

1. Измените историю/интерфейс. В `app/release.json` увеличьте `contentCode` (например, 3), `versionName` (например, 1.2.0) и напишите краткие `notes`. Не меняйте `runtimeVersion` для обычных правок контента.
2. Запустите `ПОДГОТОВИТЬ_ОБНОВЛЕНИЕ.bat`. Он собирает мобильный контент и создаёт неизменяемый ZIP и `public/releases/latest.json`. Повторная запись существующей версии запрещена: увеличьте номер. APK не включается в эти файлы.
3. Выполните тесты и опубликуйте этот же проект через Sites. Можно попросить Codex: «Проверь и опубликуй подготовленное обновление». Один BAT готовит пакет, но не публикует его без авторизации владельца сайта. Публикация должна включать ZIP и манифест одновременно. Только после успешной публикации пользователи увидят обновление.
4. Проверьте на контрольном телефоне: попап, загрузка, перезапуск, версия, сохранения, запуск без сети. Старые ZIP не удаляйте сразу: пользователь мог уже начать загрузку.

Если добавляются нативные плагины, разрешения или меняется Android-оболочка, нужен новый APK с увеличенным `versionCode` и новым `runtimeVersion`. OTA не умеет менять Android-код. Подписывайте будущие APK тем же ключом: смена ключа не позволит установить поверх старой версии. Текущая сборка использует прежний локальный debug-ключ; для магазина потребуется отдельная стратегия подписи. Не публикуйте ключи.

Это self-hosted режим открытого Capgo Updater, не подписка Capgo Cloud и не Expo. Пакеты обновлений доступны по ссылке без аккаунта; первичный APK можно продолжать распространять вручную.
